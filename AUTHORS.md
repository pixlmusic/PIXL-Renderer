# Authors and contributors

PIXL Renderer is a derived project with a long contributor history. Git history
and file-local notices are the authoritative record; this summary is not a
replacement for either.

- Community Shaders authors and contributors: upstream architecture, renderer
  infrastructure, features, shaders, build work, and retained assets. See
  `ATTRIBUTION.md` and repository history.
- PIXL Studio: PIXL Renderer modifications and independently developed PIXL
  systems during 2025-2026, only where supported by source history.
- Third-party authors: retained component and file-level notices are catalogued
  in `THIRD_PARTY_NOTICES.md` and beside the relevant component.

The repository currently uses "PIXL Studio" as its declared PIXL attribution
name. The release maintainer should confirm the desired legal copyright-holder
name before publication; this file deliberately does not invent one.
