# PIXL Renderer GUI and Control Audit

Date: 2026-08-28  
Scope: the public PIXL Renderer menu, the advanced tuner, quality profiles, shader/runtime controls, and every active final-build renderer module.

## Method and status rules

This audit used the real implementation, not GUI labels alone. Each row was followed through the applicable chain:

`ImGui/PIXLUI widget -> serialized setting/profile contract -> module state/constants/resources/defines -> HLSL or runtime consumer`

Controls separated by semicolons in one table cell were audited individually and are grouped only to keep this document usable. `VERIFIED` means the static CPU/GPU connection is present and internally consistent. It does **not** claim that a subjective visual result has been approved in Skyrim. `RUNTIME VALIDATION REQUIRED` means the static connection is valid but the result depends on live scene, camera, weather, hardware, or temporal behaviour. Developer-only diagnostics are identified explicitly and are not part of the normal player workflow.

Protected visual baseline: `PIXL-Renderer-Live-Tested.json` / the accepted live Ultra configuration. A pre-change checkpoint is stored at `build/active-dev-checkpoints/20260828-042704-gui-control-audit-baseline`.
