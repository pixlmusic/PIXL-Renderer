# Visual Fidelity Release Report

The owner's current saved look remains the Ultra/live-tested visual source. Enhanced preserves that appearance while reducing only the validated workload controls from the quality-profile contract; Ground Response visual behavior is unchanged except tessellation subdivision.

Photo Finish now combines complete fresh neural evaluations with a robust temporal resolve. Stable repeated structure carries full weight, while isolated luminance outliers from particles, animated materials or neural history receive less influence. This is designed to preserve stone, wood, foliage and character detail without the progressive blur produced by feeding an already reconstructed RGB image back into a temporal reconstruction model.

The public default remains conservative: Enhanced + TAA, NR off and FG off. This avoids vendor-dependent first-launch artifacts while retaining the approved renderer look.

Runtime acceptance still needs rapid camera turns, foliage, alpha-tested hair, fire/smoke, wet specular surfaces, dialogue, DLSS Quality/Balanced and 8/16/24-frame Photo Finish comparisons.
